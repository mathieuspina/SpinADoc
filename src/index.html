            Apparence et position

            La numérotation est écrite dans le PDF à l'enregistrement et à l'impression, comme contenu figé. Rouvert, le fichier contient déjà les numéros : une nouvelle règle s'ajouterait par-dessus.

            Tirez un cadre sur la page

            Rechercher et caviarder

            Les occurrences cochées deviennent des zones à caviarder : rien n'est détruit avant « Appliquer le caviardage ».

            Appliquer le caviardage

            Opération destructive. L'information sous les zones est détruite : chaque page concernée est remplacée par une image (à la résolution choisie) où les zones sont peintes. Le texte, les tracés, les images, les annotations et les champs de formulaire de ces pages n'existeront plus dans le fichier enregistré. Seul « Annuler » (Ctrl+Z), avant d'enregistrer, permet de revenir en arrière.

            Conséquences : sur ces pages, texte non sélectionnable ni cherchable (l'OCR est proposé ensuite) et fichier plus lourd. Les autres pages restent intactes et vectorielles. Les signets et les liens vers les pages caviardées sont retirés. Pensez aussi à « Nettoyer les métadonnées ».

            Éléments à vérifier

              Aide

              Ordre de tabulation

              Ordre dans lequel la touche Tab parcourt les champs (dans Spin A Doc et dans le fichier : ordre des champs sur chaque page). Choisissez une ligne, puis Monter / Descendre (ou Alt + flèches).

                Nettoyer les métadonnées

                Les métadonnées peuvent contenir l'information caviardée (titre, auteur, nom du fichier d'origine dans « créateur »…). Les éléments cochés sont retirés à l'enregistrement (annulable).

                Créer un tampon

                Nouvelle signature

                Le fond blanc est rendu transparent automatiquement.

                Une signature posée est une image figée dans la page. Ce n'est pas une signature électronique qualifiée ou certifiée : elle n'a pas la valeur juridique d'une signature numérique.

                Réglages

                Animations

                Par défaut, suit le réglage « réduire les animations » de Windows.

                Tampons

                Ajouté sous le tampon quand l'option « Nom » est cochée.

                Navigation

                Maintenir le bouton du milieu et bouger la souris déplace le document. Espace + glisser (bouton gauche) fait de même.

                Annotations

                Quitter l'outil : Échap, « Souris » ou un autre outil. Ctrl + clic = sélection temporaire d'un objet.

                Intégration à Windows

                Lecteur PDF

                Spin A Doc figure dans « Ouvrir avec » pour les fichiers PDF, sans remplacer votre lecteur actuel. Pour en faire le lecteur par défaut, choisissez-le dans les Paramètres de Windows.

                Spin A Doc

                100 % hors-ligne, aucune donnée envoyée : pas de connexion réseau, pas de télémétrie, pas de mise à jour automatique.

                Pour signaler un problème : collez ces informations dans votre message (version, Windows, mémoire, écrans, noms des imprimantes ; aucun nom de fichier, chemin ni contenu de document).
