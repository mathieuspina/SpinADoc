# Contribuer

Merci de votre intérêt pour Spin A Doc.

- **Signalements de bogues et suggestions** : bienvenus. Décrivez la version (Réglages > À propos), Windows, les étapes pour reproduire et
  le résultat attendu. Ne joignez aucun document confidentiel : utilisez un fichier d'exemple sans donnée réelle.
- **Failles de sécurité** : jamais en public, voir [SECURITY.md](SECURITY.md).
- **Contributions de code** : non acceptées pour l'instant. Le code est publié pour être consulté ; il reste sous « tous droits réservés »
  (voir [LICENSE](LICENSE)). Les demandes de fusion (pull requests) seront fermées sans être intégrées.
